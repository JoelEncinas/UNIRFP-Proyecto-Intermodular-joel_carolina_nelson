# Frontend BikeShare

## Que es
Aplicacion frontend tipo SPA en Angular para gestionar un sistema de bicicletas compartidas.

## Que hace
- Autenticacion de usuarios (login y registro).
- Mapa de estaciones y disponibilidad de bicicletas con Leaflet.
- Consulta de estaciones, historial de reservas y perfil de usuario.
- Visualizacion de terminos y condiciones.

## Ejecucion local
```bash
npm install
npm start
```

Abre `http://localhost:4200` en el navegador.  Usuario de prueba: `rider001 / asdasd`.

Nota: en desarrollo, el frontend espera la API backend en `http://localhost:8080`.
